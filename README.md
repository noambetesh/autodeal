# AutoDeal Mobile

AutoDeal היא אפליקציית מובייל בעברית מלאה ו-RTL לחיפוש, מעקב וניתוח עסקאות רכב בישראל.

## מה יש בפרויקט

- אפליקציית PWA עצמאית תחת `app/`
- אפליקציית Android תחת `android/`
- Backend ב-Node.js תחת `server/`
- חיפושים שמורים, מעקב, Deal Score והיסטוריית מחירים
- Telegram Bot integration
- חיבור דרך URL ציבורי של חיפוש יד2, ללא עקיפת CAPTCHA או התחברות
- שכבת מחירון עם API מורשה, מחירון ידני או חציון שוק כחלופה
- GitHub Actions לבניית APK

## בניית APK

ה-workflow בשם `Build Android APK` רץ אוטומטית על push וגם ניתן להרצה ידנית.

בסיום ה-build, הקובץ נמצא ב-Artifact בשם:

`AutoDeal-debug-apk`

ובתוכו:

`app-debug.apk`

## הפעלת השרת

```bash
cd server
node server.mjs
```

ברירת המחדל היא פורט `8787`.

בדיקה:

```bash
curl http://localhost:8787/health
```

## Telegram

במסך הגדרות באפליקציה יש להגדיר כתובת שרת, ואז להזין Bot Token ו-Chat ID. אם Chat ID אינו ידוע, שלח קודם הודעה לבוט והשאר את השדה ריק, והשרת ינסה לזהותו דרך `getUpdates`.

אין להכניס Bot Token לקוד או ל-repository ציבורי.

## יד2

יש להדביק URL של עמוד חיפוש רכבים ציבורי. AutoDeal קוראת רק מידע ציבורי שהעמוד מספק ולא עוקפת מנגנוני הגנה, התחברות או CAPTCHA.

## מחירון

אם קיים API מורשה של ספק מחירון ניתן לחבר אותו דרך ההגדרות. אחרת ניתן להזין מחיר מחירון ידנית, ובמקרה שאין מחיר כזה המערכת משתמשת בחציון שוק ומסמנת אותו כחלופה.

## Android

האפליקציה מעתיקה אוטומטית את קבצי `app/` לתוך Android assets בזמן build, לכן אין צורך לשמור עותק כפול של קבצי ה-web בתוך `android/`.
